# 🐣 团团养成 (Tuantuan Pet Game)

一个基于 HTML/CSS/JavaScript 的纯前端 Web 宠物养成游戏。

## ✨ 游戏特色
- **丰富的数值系统**：饱腹、快乐、经验、亲密度、学识、精力。
- **多线发展**：从文盲到博士的学历晋升，解锁 30+ 专业。
- **打工系统**：学历决定身价，小心黑心老板！
- **图鉴收集**：探索事件与学习事件图鉴，还有绝世稀有传说。
- **特色机制**：每日签到、考试阴影、梦境预言、盲盒等。

## 🚀 如何游玩
1. 克隆或下载本仓库。
2. 直接双击 `index.html` 即可在浏览器中游玩，无需后端服务器。
3. 存档会自动保存在浏览器的 `localStorage` 中。

## 🛠️ 技术栈
- 原生 HTML + CSS + JavaScript (无第三方框架，极致轻量)
